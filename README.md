# DanaTech — فروشگاه لوازم جانبی موبایل در ایران

- زبان پیش‌فرض فارسی؛ نسخهٔ انگلیسی در `/en/`.
- کاتالوگ ۱۰۰ محصول در ۷ دسته؛ صفحه‌بندی ۱۰ محصول در هر صفحه.
- صفحهٔ جزئیات اختصاصی هر محصول در `/product/{id}` و سفارش از دایرکت `@bezii.pv`.
- کارت‌های محصول کم‌جزئیات؛ مشخصات فنی تأییدنشده یا قیمت ساختگی نمایش داده نمی‌شود.
- بنر ارسال سریع پس از تأیید موجودی و نشانی؛ زمان تحویل تضمین نشده است.
- بدون لینک Amazon.
