# DanaTech — فروشگاه لوازم جانبی موبایل در ایران

فروشگاه ایستا و واکنش‌گرا با زبان پیش‌فرض فارسی، نسخهٔ انگلیسی، کاتالوگ ۱۰۰ محصول و سفارش از طریق دایرکت اینستاگرام.

## امکانات
- صفحهٔ اصلی فارسی و راست‌چین؛ نسخهٔ انگلیسی در مسیر `/en/`
- دسته‌بندی مستقل محصولات در صفحهٔ اصلی
- پوسترهای SVG داخلی و بدون وابستگی به سرویس تصویر خارجی
- جست‌وجو و فیلتر دسته‌بندی
- ثبت سفارش از طریق Instagram Direct پس از تنظیم نام کاربری فروشگاه در `app.js`
- بدون لینک یا ارجاع خرید به Amazon
- بدون قیمت یا موجودی ساختگی؛ قیمت و موجودی از طریق دایرکت تأیید می‌شود

## بازار هدف
بازار هدف ایران است. قیمت‌ها در سایت درج نمی‌شوند تا قیمت روز و موجودی پیش از سفارش از طریق دایرکت تأیید شود. شرایط ارسال و پرداخت باید با مشتری هماهنگ شود.

## استقرار
پروژهٔ استاتیک است و مستقیماً روی Vercel منتشر می‌شود؛ نیازی به build command ندارد.
